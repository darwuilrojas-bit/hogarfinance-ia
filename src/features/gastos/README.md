# Gastos

Registro y categorización de los gastos del hogar (manual y asistida
por IA a partir de comprobantes).

Estructura sugerida al implementar:

- `components/` — formulario de gasto, lista de gastos, filtros
- `hooks/` — CRUD de gastos contra Supabase
- `types.ts` — tipo `Gasto`, categorías, etc.
