# Dashboard (Inicio)

Resumen general de las finanzas del hogar: gastos del mes, próximos
vencimientos y actividad reciente.

Estructura sugerida al implementar:

- `components/` — tarjetas de resumen, gráficos, accesos rápidos
- `hooks/` — obtención de datos agregados desde Supabase
- `types.ts` — tipos propios de la funcionalidad
