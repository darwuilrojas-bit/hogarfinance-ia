# Alertas (Vencimientos)

Vencimientos de servicios, impuestos y cuotas, con recordatorios
inteligentes antes de cada fecha.

Estructura sugerida al implementar:

- `components/` — lista de vencimientos, badges de urgencia
- `hooks/` — CRUD de vencimientos y cálculo de próximos avisos
- `types.ts` — tipo `Vencimiento`, niveles de alerta, etc.
