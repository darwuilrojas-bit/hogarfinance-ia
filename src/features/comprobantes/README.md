# Comprobantes

Carga y almacenamiento de facturas, recibos y tickets usando
Supabase Storage, con extracción de datos mediante IA.

Estructura sugerida al implementar:

- `components/` — carga de fotos/archivos, galería, detalle
- `hooks/` — subida a Supabase Storage y registro en base de datos
- `types.ts` — tipo `Comprobante`, estados de procesamiento, etc.
